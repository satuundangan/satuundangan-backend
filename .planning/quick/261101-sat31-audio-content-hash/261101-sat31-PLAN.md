# SAT-31: Detect duplicate audio files by content

## Goal
Admin can find byte-identical audio assets even when they have different storage URLs.

## Scope
- Store a nullable SHA-256 digest for audio uploaded or replaced through admin audio flows.
- Return duplicate content counts with catalog entries; retain exact URL counts for legacy metadata.
- Show an explicit warning in the audio manager and state that older un-hashed records are not assessed.

## Constraints
- Target `development` only; no production deploy or production data access.
- Hash original uploaded bytes before storage, without downloading arbitrary URLs.
- No tests requested; validate both builds and inspect diff.

## Verification
- Backend `npm run build`.
- Frontend `CI=1 npm run build`.
- `git diff --check` in both repositories.
